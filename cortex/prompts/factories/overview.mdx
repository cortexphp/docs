Prompt factories let you manage prompts outside your codebase and load them by name at runtime. Cortex ships with three factory drivers.

## Basic Usage

```php
use Cortex\Prompts\Prompt;

// Using the default factory driver
$prompt = Prompt::factory()->make('my-prompt-name');

// Using a specific driver
$prompt = Prompt::factory('langfuse')->make('my-prompt-name');
$prompt = Prompt::factory('blade')->make('geography');
$prompt = Prompt::factory('mcp')->make('my-mcp-prompt');
```

Via the `Cortex` facade:

```php
use Cortex\Cortex;

$prompt = Cortex::prompt()->factory('langfuse')->make('test-prompt');
$result = $prompt->llm()->invoke(['country' => 'France']);
```

The returned `$prompt` is a `PromptTemplate` that you can invoke like any other prompt.

## Setting the Default Factory

```bash
CORTEX_DEFAULT_PROMPT_FACTORY=langfuse
```

Then `Prompt::factory()` with no argument uses Langfuse.
